#Moisture Sensor

Esp32-C3 mini powering a small i2c oled, an led and a moisture sensor. 
these compenents work together to determine the soil moisture level, display the 
raw input and soil state on the oled and watering need on the led. 

Parts List:
1: Esp32-C3 Mini
2: 5mm red LED
3: 0.96" I2C SSD1306 OLED
4: 220Ω Resistor
5: Capacitive Soil Moisture Sensor V1.2
